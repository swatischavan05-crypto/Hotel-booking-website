🏨 Hotel Booking Website

A responsive Hotel Booking Website built using HTML, CSS, and JavaScript. Users can select an Indian state, city/district, and area to search for available hotels and simulate a complete hotel booking process.

🌟 Features
🇮🇳 State-based hotel search
🏙️ City/District selection
📍 Area-based hotel search
🔍 Dynamic hotel filtering
🏨 Hotel listings with:
Hotel name
Location
Rating
Price per night
Facilities
⭐ Rating filter
💰 Price filter
📋 Hotel details
📅 Check-in and check-out selection
👥 Guest and room selection
📝 Guest booking form
🎫 Automatic booking ID generation
✅ Booking confirmation
💾 Booking data stored using LocalStorage
🌙 Dark mode
📱 Responsive design
🎨 Modern and user-friendly interface
🛠️ Technologies Used
HTML5
CSS3
JavaScript
DOM Manipulation
LocalStorage
📁 Project Structure
hotel-booking-website/
│
└── index.html

The entire project is contained in a single index.html file, including the HTML structure, CSS styling, JavaScript functionality, location data, hotel data, search system, filters, and booking system.

🔎 How It Works
Select an Indian State.
Select a City/District.
Select an Area.
Click Search.
Browse available hotels.
Apply price or rating filters.
Click Details to view hotel information.
Click Book Now.
Enter guest and stay details.
Confirm the booking.
Receive a unique booking ID.
📅 Booking System

The website provides a simulated booking system where users can enter:

Full Name
Email
Phone Number
Check-in Date
Check-out Date
Number of Guests
Number of Rooms

After confirmation, a unique booking ID is generated and the booking information is stored in the browser using LocalStorage.

🌙 Dark Mode

The website includes a dark mode option that allows users to switch between light and dark themes.
